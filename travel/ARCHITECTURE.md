# ARCHITECTURE.md — JamaxTravel

## Overview

Static marketing site built with **Astro** (static output, no server, no database).
Content lives as files in the repo; Astro validates it against a schema at build time and
renders plain HTML/CSS with one small script (category filter). Hosting: **Vercel**.

```
content files (JSON)  ──►  Astro build (schema validation + templates)  ──►  dist/ (static HTML)  ──►  Vercel
```

**Phase:** proof of concept. Editing is local (edit file → preview → deploy). No CMS, no auth, no payments.

## Stack

| Concern | Choice | Notes |
|---|---|---|
| Framework | Astro 7.3.8 (pinned) | 7.4+ requires Node ≥ 22.23.4; local machine has 22.20. Upgrade Node, then Astro. |
| Templates | `.astro` components | Layouts, components, props, slots, loops — Blade/Twig equivalent. |
| Content | Astro content collections (`glob` loader, JSON) | Zod schema in `src/content.config.ts`. |
| Styles | One global stylesheet, CSS custom properties | `src/styles/global.css`, tokens documented in `DESIGN.md`. No Tailwind. |
| JS | Single inline module (category filter) | Progressive enhancement: all promos visible without JS. |
| Fonts | system-ui + EB Garamond (Google Fonts) | |
| Images | Remote Unsplash URLs, resized via query params | `img()` helper; non-Unsplash URLs pass through untouched. |
| Hosting | Vercel (Hobby during PoC) | Hobby is non-commercial — move to Pro before commercial launch. |

## Content model

### Promo — `src/content/promos/<slug>.json`

| Field | Type | Required | Purpose |
|---|---|---|---|
| `published` | boolean | default `true` | `false` hides the promo everywhere without deleting it |
| `order` | integer | default `999` | Sort order (ascending); first 4 also feed "¿A dónde quieres ir?" |
| `title` | string | ✓ | Card + detail headline |
| `destination` | string | ✓ | "City, Country"; text before the comma is the destination tile label |
| `origin` | string | ✓ | e.g. "Salida desde Medellín" |
| `nights` | integer > 0 | ✓ | |
| `category` | string | ✓ | Drives the home filter pills (free text, keep consistent) |
| `badge` | string | ✓ | Short urgency/label chip |
| `priceFrom` | integer > 0 | ✓ | COP, no separators (`1499000`) |
| `priceNote` | string | default | "por persona en acomodación doble" |
| `departure` | string | ✓ | Free-text suggested departure |
| `season` | string | ✓ | |
| `hotel` | string | ✓ | Hotel + meal plan |
| `images` | URL[] (≥ 5) | ✓ | Order matters — see DESIGN.md §7 |
| `summary` | string | ✓ | Intro paragraph + meta description |
| `includes` | string[] (≥ 1) | ✓ | |
| `excludes` | string[] | default `[]` | Section hidden when empty |

Invalid content **fails the build** with a field-level error, so a broken promo never reaches production.

### Site settings — `src/data/site.json`

`brand`, `whatsapp` (international format, digits only), `operator`, `rnt`,
`announcement { text, linkText, promo }` (promo = slug; empty `text` hides the bar),
`highlights[] { icon, title, detail, accent: blue|red|amber }` (max 4 used).
Not schema-validated yet — keep the shape.

## Routing

- `/` — home.
- `/promos/<slug>/` — generated by `getStaticPaths()` for every published promo.
- Unpublished promos produce no page; links to them must be removed (announcement included).

## Conversion flow

Every CTA is a `wa.me` deep link built by `waLink()`. With a promo it pre-fills
`Hola JamaxTravel, quiero cotizar la promo "<title>" (<departure>).` so the advisor knows the context.
No forms, no tracking, no cookies yet.

## Build and deploy

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # validates content + writes dist/
npm run preview   # serve dist/
vercel --prod     # deploy (Vercel CLI, framework auto-detected as Astro)
```

Vercel settings: framework Astro, build `npm run build`, output `dist`. No env vars needed.
